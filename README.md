# 장기 알까기 · v0.6

나무 장기판과 장기알의 물성을 바탕으로 한 알까기 게임입니다. 혼자 하기, 한 기기 둘이서, 방 코드를 이용한 온라인 2인 대전을 제공합니다. 독립 Vite 프론트엔드와 별도의 Node.js WebSocket 게임 서버로 구성되어 있습니다.

## v0.6 연출 보강

독립 Astra 에이전트가 화면·음향 연출을 수정했습니다. 강타의 이동 표시부터 첫 접촉까지 연결하고 340ms 강타 인장을 추가했으며, 강타 발사와 첫 접촉 소리를 일반 샷과 구분했습니다. 낙하음에는 90ms 지연을 적용했습니다. 물리·스킬 배율·온라인 코드는 v0.5와 동일합니다.

`docs/janggi/astra-v06-comparison.gif`는 동일한 강타 물리에 v0.5와 v0.6 화면을 적용한 무음 네이티브 렌더 비교입니다. 실제 브라우저 녹화가 아니며 비교에서는 화면 흔들림을 껐습니다. 오디오의 실제 청취 평가는 수행하지 못했습니다.

## 시작하기

Node.js 24를 설치한 뒤 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

온라인 대전에는 별도 터미널에서 게임 서버도 실행합니다.

```sh
npm run server
```

개발 중 프론트엔드는 기본적으로 로컬 서버에 연결합니다. 방을 만든 뒤 표시된 코드를 다른 플레이어에게 전달하고, 양쪽이 준비하면 게임이 시작됩니다. 온라인 게임의 판정과 물리는 서버가 담당합니다. 접속이 끊긴 플레이어의 재접속과 경기 후 재대결을 지원합니다. 관전은 아직 지원하지 않습니다.

```sh
npm test
npm run build
npm run preview
```

`dist/`는 프론트엔드의 배포용 빌드입니다. 직접 파일을 열기보다 개발 서버 또는 미리보기 서버를 이용하세요.

## 플레이

- 혼자 하기에서는 아래 청색 초楚를 사람이, 위 홍색 한漢을 AI가 조작합니다. 한 기기 둘이서는 같은 화면에서 번갈아 둡니다.
- 내 돌을 뒤로 당겼다가 놓으면 발사합니다. 돌이 멈추면 차례가 바뀝니다.
- 상대 돌이 모두 사라지면 승리합니다. 마지막 양쪽 돌이 함께 사라지거나 200수에 도달하면 무승부입니다. 왕이 떨어져도 즉시 패배하지 않습니다.
- 판에 키보드 포커스를 둔 뒤 Q/E로 돌 선택, 숫자 1~9로 빠른 선택, 방향키로 조준과 힘 조절, Enter/Space로 발사, Escape로 조준 취소를 할 수 있습니다.

## v0.5 강타와 타격 연출

각 플레이어는 경기당 한 번 `파죽지세`를 켜고 발사할 수 있습니다. 승인된 샷의 충격량만 1.25배가 되며, 거부된 입력은 횟수를 소모하지 않습니다. 일반 발사 물성은 v0.4와 같습니다. 첫 충돌의 금빛 강조, 고속 피격 말의 잔상, 힘별 발사 음량과 강한 타격음 우선 재생을 추가했습니다. 현재 스킬은 이 한 종류입니다. 솔로 AI는 스킬을 사용하지 않습니다.

## 검증 범위

코어 30개, 실제 localhost WebSocket 통합 3개, 연출 상태 검사 3개로 총 36개 테스트 및 TypeScript/프로덕션 빌드가 통과했습니다. 두 연결의 입장·준비·발사 권한·강타·중복 명령·재접속·재대결을 검사했습니다. 오디오 API 모형 검사와 독립 Canvas 렌더링도 확인했습니다. 실제 두 기기의 브라우저 조작, 인터넷 배포, 스피커 청취 및 Docker 이미지 빌드는 아직 검증하지 않았습니다. Rapier WASM이 메인과 AI Worker에 각각 들어가 초기 다운로드가 큰 한계가 남아 있습니다.

## 배포

프론트엔드와 WebSocket 서버를 각각 배포해야 합니다. Vercel 프로젝트에서 이 폴더를 루트로 선택하고 다음 설정을 사용하세요.

- Framework: Vite
- Install: `npm ci`
- Build: `npm run build`
- Output: `dist`
- 빌드 환경변수: `VITE_GAME_SERVER_URL=wss://your-game-server.example.com`

`VITE_GAME_SERVER_URL`은 프론트엔드 **빌드 시** 포함됩니다. 서버 주소가 바뀌면 환경변수를 바꾸고 다시 빌드·배포하세요. HTTPS 프론트엔드에서는 보안 WebSocket인 `wss://` 주소를 사용하세요. 운영 빌드에 주소가 없으면 온라인 모드에서 설정 오류를 안내합니다.

게임 서버는 WebSocket 연결을 유지할 수 있는 별도 Node.js 호스팅에 배포합니다. 서버는 데이터베이스 없이 메모리에 방을 보관하므로 서버를 재시작하면 방과 진행 중인 경기가 사라집니다. 상세 설정과 Docker 실행은 [온라인 배포 안내](docs/online-v05.md)를 참고하세요. 실제 배포는 수행하지 않았습니다.

## 구성

| 경로 | 역할 |
| --- | --- |
| `src/core/` | Rapier 물리, 턴, 발사 검증, 승패, 스냅샷 |
| `src/players/` | AI 후보 탐색과 Worker |
| `src/view/`, `src/audio/` | 판·돌·효과 렌더링 및 오디오 |
| `src/net/` | 온라인 통신 및 메시지 |
| `server/` | 온라인 방과 권위 있는 게임 서버 |
| `tests/` | 코어와 통신 검증 |

고정 물리는 120Hz이며 화면 연출과 소리는 판정과 분리됩니다. Rapier 버전과 의존성 lockfile을 포함합니다.

## 이전 버전과 제작 자료

v0.4는 솔로 및 한 기기 대전을 중심으로 발사 제동, 경첩 위치, 충돌 반동과 오디오를 조율했습니다. 당시의 온라인 미구현 및 검증 범위는 과거 기록이며 v0.5의 현재 기능을 설명하지 않습니다. 물성 자료는 `docs/janggi/gamefeel-v04.md`, 제작 과정은 `docs/production-workflow.md`, 과거 PvP 설계 검토는 `docs/pvp-architecture.md`에 있습니다. Suno는 연결되지 않았으며 게임에 포함된 WAV 샘플을 사용합니다.
