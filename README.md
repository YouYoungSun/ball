# 장기 알까기 · v0.2

나무판의 분위기를 유지하면서 장기알의 크기와 질량, 상하 진영, 접이식 경첩을 게임 규칙으로 만든 솔로 게임입니다. Sites를 사용하지 않는 독립 Vite 프로젝트입니다.

## 실행

Node.js 24 LTS를 사용합니다. 테스트는 Node의 TypeScript 타입 제거 기능을 사용합니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/`는 배포용 빌드입니다. 개발자 도구 없이 파일을 직접 더블클릭하는 대신 개발/미리보기 서버로 실행합니다. 테스트는 Node.js 24에서 검증했습니다.

## 플레이

- 혼자 하기: 아래 청색 초楚는 사람, 위 홍색 한漢은 후보 샷을 시험하는 AI입니다. AI 탐색은 Web Worker에서 실행합니다.
- 한 기기 둘이서: 초·한이 같은 화면에서 번갈아 둡니다. 인터넷 PvP는 아닙니다.
- 내 돌을 뒤로 당겼다가 놓으면 발사합니다. 모든 돌이 멈추면 차례가 바뀝니다.
- 상대 돌이 모두 사라지면 승리합니다. 마지막 양쪽 돌이 함께 사라지면 무승부입니다. 200수에 도달하면 무승부입니다. 왕 하나가 떨어져도 즉시 패배하지 않습니다.
- 판에 키보드 포커스를 둔 뒤 Q/E로 내 알을 순환 선택하고 숫자 1~9로 빠른 선택, 좌우 방향, 위아래 힘, Enter/Space 발사, Escape 조준 취소를 지원합니다.
- 탭을 숨기거나 쉬기 버튼을 누르면 물리 진행을 멈춥니다. 온라인 모드의 일시정지 규칙은 별도로 정의해야 합니다.

## Vercel

이 폴더를 Git 저장소의 루트로 사용하거나 Vercel 프로젝트의 Root Directory로 선택합니다.

- Framework: Vite
- Install: `npm ci`
- Build: `npm run build`
- Output: `dist`

`vercel.json`이 포함되어 있습니다. DB, API 키, 환경변수, Suno 연결 없이 현재 게임은 실행됩니다. 실제 배포나 GitHub 연결은 수행하지 않았습니다.

## 구성

| 경로 | 역할 |
| --- | --- |
| `src/core/` | DOM 없는 Rapier 물리, 턴, 발사 검증, 승패, 샷 로그, 스냅샷 |
| `src/players/` | AI 후보 탐색과 Worker |
| `src/view/` | 선택한 나무판, 돌, 조준, 충돌 섬광, 낙하, 흔들림 |
| `src/audio/` | 실제 WAV 샘플, 질량별 음색, 경첩 금속음, 동시 발음 제한 |
| `src/net/` | 교체 가능한 통신 인터페이스, 루프백, 호스트 권한 검증 |
| `tests/` | 재현·복원·권한·발사·턴·낙하·전송 검사 |

고정 물리는 120Hz이며 연출의 프레임률·소리·흔들림이 판정에 영향을 주지 않습니다. Rapier는 정확한 버전으로 고정하고 lockfile을 포함했습니다.

## 스킬과 Suno MCP

디자인/검수 지침은 제작 과정에 적용했습니다. 스킬을 실행 라이브러리로 설치하거나 MCP 서버를 게임에 넣는 구조는 아닙니다. `docs/production-workflow.md`를 참고하세요.

Suno는 **미연결**입니다. 이번 버전에는 외부 샘플 없이 직접 합성·제작한 WAV 21개가 포함되어 있습니다. 발사/경·중·중량 충돌/금속 경첩/낙하/마침음 각 3변주입니다. `public/audio/manifest.json`으로 재생 파일을 지정합니다. 파일은 미리 로드하고 첫 입력에서 오디오를 활성화합니다. 파일 로드 실패 시 삐 소리로 대체하지 않습니다. 비교음은 `docs/audio/audition.wav`, 재생성 스크립트는 `scripts/audio/sound-design.py`입니다.

## 장기알의 물성 및 경첩

- 각 진영 16개, 전체 32개입니다. 판은 9선·10줄과 양끝 궁성으로 구성합니다. 장기의 행마 규칙 대신 알까기 발사 규칙을 사용합니다.
- 같은 드래그에서 무거운 알이 더 큰 운동량을 가지도록 종류별 최대속도와 질량에 맞는 발사 impulse 한도를 사용합니다.
- 왕 2.8, 차 2.0, 포 1.8, 상 1.4, 마 1.3, 사 0.9, 졸 0.65의 게임용 상대 질량을 적용했습니다. 실제 장기알의 측정 무게가 아닙니다.
- 중앙 접힌 선은 통과합니다. 선 양끝의 금속 경첩 두 개만 짧은 고정 충돌벽입니다.
- 판은 Canvas 가로의 94.5%를 차지합니다. 세로로 긴 상하 대결 구조입니다.
- 상세 조율과 검사 결과는 `docs/janggi/design-review.md`, 현재 판 이미지는 `docs/janggi/board-ready.png`입니다.

## 후속 PvP

코어를 재사용할 수 있는 구조지만 **온라인 PvP는 구현하지 않았습니다**. 실제 WebRTC/WebSocket 어댑터, signaling, TURN, 접속별 신원과 side 지정, 메시지 스키마, ACK 재시도, 체크섬, 재접속이 필요합니다. 상세 판단과 현재 검증 범위는 `docs/pvp-architecture.md`에 정리했습니다.

## 검증과 남은 한계

- 코어 테스트 22개 통과. 질량에 따른 반동, 종류별 발사 한도, 경첩 반사/중앙 통과, 경첩 스냅샷 복원을 추가했습니다.
- `node scripts/audio/check-player.ts`로 21개 WAV 연결, 물성별 음색 선택, 동시 발음 제한과 음소거를 검사합니다. 실제 브라우저 디코딩/청취 대신 API 모형을 사용한 검사입니다.
- Node에서 독립 코어의 재현, 움직이는 중 스냅샷 복원, 샷 로그 재생, 잘못된 발사 거부, 낙하/승패, 호스트 권한, 루프백 세션 하네스를 검사했습니다.
- TypeScript와 프로덕션 빌드를 검사했습니다.
- Canvas를 별도 렌더러로 확인했습니다. 환경 제한으로 실제 브라우저, 기기 간 결정성, 모바일 터치, 오디오 청취 검증은 하지 못했습니다.
- Rapier WASM이 메인/Worker 빌드에 각각 포함되어 초기 전송량이 큽니다. Worker는 첫 AI 차례에 생성됩니다. 정식 배포 전 공통 WASM 자산 분리와 모바일 성능 확인을 권장합니다.
- UI는 Noto Serif KR을 Google Fonts에서 요청하며, 연결이 없으면 시스템 글꼴로 대체합니다.
