# C — 한 호흡, 끊어치는 먹

가설 타임라인: 준비 중 두 개의 마른 붓 괄호가 선택 말의 뒤쪽으로 조여든다. 강타는 두꺼운 먹과 가느다란 여백의 세 겹, 일반은 한 겹이다. 발사 0~180ms는 실제 이동 경로 위에 넓게 눌렀다 가늘어지는 먹을 남긴다. 강타의 경로는 420ms까지 기억하되 실제 말의 외곽은 가리지 않는다. 접촉 0~55ms에 먹선의 흐름을 접선 방향의 밝은 칼자국으로 끊는다. 55~180ms는 두 갈래의 짧은 먹 파편이 접촉 접선을 따라 갈라진다. 피격 말은 실제 이동의 짧은 붓 흔적을 물려받는다. 180~420ms는 먹이 마르듯 사라진다. 탈락은 별개의 하향 점 세 개와 90ms 뒤 낮은 목질 착지로 구분한다.

버림: 기존 강타 인장, 접촉 괄호, 황금 잔상, 전판 흔들림, 기존 효과음 재생을 모두 사용하지 않는다. 원래 나무판/말/실제 조준선/낙하는 보존한다. 화려한 범위 원이나 성공 글자는 없다.

오디오는 합성한 짧은 마찰음→건조한 목질 클릭→강타 첫 실제 접촉에서만 낮은 공명과 늦은 짧은 끊김으로 설계한다. 경첩은 금속성 고주파 두 음, 낙하는 지연된 저주파로 분리한다. 약한 연쇄 접촉은 시간 간격으로 제한한다. 준비음은 API에 없으므로 무음으로 둔다.

core state는 읽기만 하며 경로/접촉/음향 상태는 독립 보관한다. reduced motion에서는 경로를 생략하고 준비 괄호와 짧은 접촉 획만 유지한다. effects=false는 독자 효과도 끈다. clear/reset은 모든 보류 연출을 비운다.

직접 확인: `npx tsc --noEmit` 통과. 브라우저 화면·모바일 동영상·실제 청취·기기 성능은 아직 확인하지 않음. 미적 합격이나 식별률 점수를 주장하지 않는다.
