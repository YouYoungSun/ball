# B — 압축된 쐐기 / 아케이드

시간은 검증 전 가설이다. 나무판과 팔각 장기알은 유지하고 기존 강타 인장, 붓 같은 발사 획, 전역 흔들림을 버린다. 준비 시 두 굵은 꺾쇠가 알을 향해 압축되고, 발사 때 뒤로 찢어진다. 강타 비행에는 두 개의 단단한 기하 레일이 붙는다. 첫 실제 접촉에서만 밝고 어두운 접촉 면과 방향 쐐기가 열린다. 범위를 나타내는 원형 폭발은 없다.

- 준비: 힘에 따라 알 바깥의 네 모서리가 가까워짐. 일반은 얇은 두 선, 강타는 두꺼운 황동/먹색 쐐기.
- 발사 0–150ms: 압축 모서리가 뒤로 열리며 잔상. 일반은 짧은 한 획.
- 첫 강타 접촉 0–52ms: 두 당사자의 복사된 표시 좌표만 고정. 물리·서버·입력 시간은 그대로. 국소 접촉 면을 선명하게 유지.
- 52–117ms: 표시 좌표를 최신 실제 좌표로 복귀. 접촉 면은 방향성 작은 파편으로 분해.
- 피격 60–240ms: 피격 알 방향의 세 쐐기만 분리. 연쇄 접촉은 90ms 작은 표식.
- 탈락 0–700ms: 기존 나무알 낙하를 보존하고 경계의 좁은 두 획이 아래로 흘러 사라짐. 성공 표시는 실제 removed 이벤트 이후에만.

음향은 임시 합성: 발사 고역 마찰의 짧은 하강, 접촉의 건조한 대역 제한 노이즈+목재 공명, 강타 첫 접촉은 24ms 후 낮은 공명을 분리, 경첩 금속 부분음, 낙하는 90ms 뒤 내려가는 공명. 음량만 증가시키지 않는다. 음소거/reset/suspend 시 예약 소스도 중단한다.

동작 줄이기(effects=false)에서는 준비의 정적 강타 모서리만 유지하고 비행·접촉·좌표정지를 제거한다. shaking 플래그와 무관하게 전역 흔들림은 사용하지 않는다.

검증 상태: 구현과 TypeScript 검사는 아래 보고로 기록. 브라우저 육안·휴대폰·음향 청취·영상·프레임 측정은 공통 실험 도구에서 별도 수행해야 하며 이 문서는 미적 합격을 주장하지 않는다.

실행 검증: `npx tsc --noEmit` 두 차례 통과(2026-11-13). 변경 파일은 본 후보의 index.ts/design.md뿐이다. 강타 첫 접촉도 strength ≤ .18이면 좌표정지와 큰 접촉면을 생략해 약한 스침을 과장하지 않는다. 화면/소리 관찰은 아직 하지 않았으므로 모바일 식별성·청취·반복 피로·프레임 성능은 미검증이다.

접근성 QA 수정: effects=false에서는 base에 removed를 전달하지 않고 render 시 기존 base 낙하 목록을 clear한다. 이미 진행 중인 낙하도 동작 줄이기를 켜면 즉시 사라지며 실제 state 위치·생존에는 변경이 없다. 수정 뒤 TypeScript 재검사 통과.
