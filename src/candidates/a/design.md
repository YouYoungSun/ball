# A — 손끝과 나무

타임라인은 첫 구현 가설이다. 실제 물리·판정 시간과 분리한다.
- 준비: 힘을 줄수록 말의 윗면이 뒤로 기울고 두꺼운 측면이 보인다. 강타에서는 더 짙어진 접지 그림자와 뒤쪽의 손끝 모양 압력 자국이 생긴다. 글자 배지는 없다.
- 방출 0–160ms: 말은 낮게 들렸다가 즉시 판에 접지한다. 강타만 접지 전에 뒤쪽 나무가루가 퍼진다. 속도선이나 먹선은 없다.
- 접촉 0–50ms: 실제 접촉점의 어두운 면과 밝은 모서리만 단단히 닫힌다. 1차 강타의 표면 반응이 크고 후속 접촉은 실제 strength만 따른다.
- 피격 0–240ms: 피격 말의 윗면이 접촉 방향으로 기울었다 되돌아온다. 무거운 말은 덜 기울고 더 낮은 공명음을 낸다. 중심 위치·반지름은 물리값이다.
- 낙하 0–420ms: 옆면이 보이며 아래로 사라진다. 170ms 뒤 낮은 두 번의 나무 바닥음. 승리 효과음은 생략하여 마지막 낙하를 덮지 않는다.

버린 것: 강타 인장, 방향 붓자국, 이동 후광, 접촉 괄호, 화면 흔들림, 원형 힘 게이지, 기존 Foley 샘플. 판만 원본 renderer에서 가져오고 말을 직접 그린다. 음향은 짧은 감쇠 목재 공명과 접촉 노이즈를 합성한다.

검증 구분: `npx tsc --noEmit` 통과(2026-11-13). 브라우저 실제 조작/모바일 영상/음향 청취는 공동 캡처 담당에게 의뢰하며 그 전에는 품질 합격을 주장하지 않는다. corestate를 쓰는 코드 없음. effects=false이면 준비 기울기·접촉·낙하 이동 효과를 끈다. shaking 값과 무관하게 화면 흔들림은 사용하지 않는다.

## 1차 수정 — native 390px 프레임 직접 관찰 뒤

관찰: power/normal 0012,0020,0022,0023,0024,0026을 직접 열었다. 준비 둘레/압력자국은 구분되나 power 피격의 긴 갈색 측면은 나무가 박히는 대신 기둥처럼 떠 있는 모습이었다. 가루는 몇 점으로 작았다. 정상속도 영상 판별/청취는 하지 않았다.

수정: 발사·접촉의 수직 lift를 제거했다. 아랫면/옆면 두께를 고정하고 윗면에만 방향성 기울기(최대 24%)와 작은 비대칭 이동을 적용한다. 준비는 발사 반대 방향으로 눌리고 발사 시 즉시 반대로 풀린다. 강타 접촉점은 105ms 어두운 접촉면+밝은 가장자리로 잡고, 이후 윗면이 감쇠 복귀한다. 질량별 각도 차이는 유지한다. 옆면 때문에 전체 말이 위로 뜨는 현상을 없애는 것이 목적이며 강약 판별 성공은 재캡처 관찰 전 미확정이다.

수정 후 `npx tsc --noEmit` 통과. core/state/event 수정 없음.
