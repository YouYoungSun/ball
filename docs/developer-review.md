# 개발자 검토 결과

2026-11-13, 개발자 서브에이전트와 구조를 논의하고 구현 후 판정·복원·권한 경계를 다시 검토했습니다.

## 합의

- 이전 나무판 디자인을 유지하며 Vite + TypeScript + Canvas2D + Rapier2D로 시작합니다.
- 시안의 직접 만든 간이 충돌과 시간축 연출은 정식 판정으로 재사용하지 않습니다.
- 게임 코어, 플레이어 입력, 화면, 음향, 통신을 분리합니다. Suno와 디자인 스킬은 제작 과정에 위치합니다.
- 첫 온라인은 호스트 권위 친구 대전이 적합하고, 공식 경쟁전은 서버 권위로 확장합니다.

## 코드 검토에서 수정한 사항

- 손상된 스냅샷 복원 실패 시 WASM world와 queue를 해제합니다.
- AI 후보 탐색을 try/finally로 감싸 정상·예외 경로 모두 world를 해제합니다.
- 호스트의 null/객체가 아닌 명령을 거부합니다. 완전한 원격 메시지 스키마와 인증은 온라인 작업 범위입니다.
- 명령 전달·권한 검사 각각의 테스트 외에 호스트→ACK→체크포인트→게스트 복원 루프백 통합 하네스를 추가했습니다.

## 완료된 검증

16개 테스트 통과, TypeScript 검사와 Vite 프로덕션 빌드 통과. Canvas의 대기·실제 물리 충돌·샷 종료 프레임을 별도 렌더로 검토했습니다. 좌표 변환 검사도 통과했습니다.

## 아직 검증하지 않은 것

실제 브라우저의 전체 UI, 모바일 터치/오디오, 기기 간 결정성, 인터넷 지연·재접속·TURN, 원격 입력의 보안 경계. 현재 UI는 로컬 게임 코어를 사용하며 온라인 transport와 연결되어 있지 않습니다.

따라서 표현은 **PvP에 재사용할 경계를 갖춘 솔로 첫 버전**이며, 온라인 PvP 완성이나 실서비스 검증 완료는 아닙니다.
