# v0.4 타격감 조율

이전 세션을 전달하지 않은 독립 에이전트 세 명이 물리, 충돌 연출, 음향을 각각 검토하고 구현했습니다. 통합 시 초반 속도를 유지한 세 가지 제동 후보를 비교해 저속 제동을 강화한 C안을 선택했습니다.

## 물리

졸의 최대 초기속도를 8.2에서 12로 복원했습니다. 150ms 유예 뒤 250ms에 걸쳐 제동을 올리고, 이동거리와 낮은 속도에 가중치를 줍니다. 충돌할 때마다 유예를 다시 주지 않습니다. 저속에서는 정지점에 수렴시키고 조용한 24 tick 후 차례를 넘깁니다. 첫 150ms가 무마찰이라는 뜻은 아닙니다.

왕 질량 2.8, 졸 0.65 등 크기별 기존 질량을 유지합니다. 경첩 중심은 9×10 물리판의 (1.8, 5), (6.9, 5)이며 각 반폭 .65, 반높이 .23입니다. 접힌 선의 나머지 부분은 통과합니다.

| 재현 항목 | 결과 |
| --- | --- |
| 최대 졸 발사 초기속도 | 12 |
| 단독 졸 발사 150ms 이동거리 / 속도 | 1.775 / 11.649 |
| 단독 졸 최대 이동거리 / 차례 종료 | 7.675 / 약 1.233초 |
| 초기 중앙 졸→병→왕, 힘 40% / 65% / 80% / 100% | 왕 이동 0 / .217 / .497 / .930 |
| 위 네 샷의 상대 왕 | 모두 생존 |

단위는 물리판 좌표입니다. 특정 중앙 시작 배치의 회귀 검사이며 모든 상황에서 왕이 생존한다는 뜻은 아닙니다. 왕도 가장자리에서는 떨어지며 별도의 피해 제한이나 무적 규칙은 없습니다.

## 연출과 소리

충돌 방향의 한 번 반동은 105ms, 최대 3.2 Canvas px입니다. 약한 충돌에는 흔들림을 생략합니다. 접촉 표시는 75~140ms, 빠른 발사 잔상은 초반 110ms만 표시합니다. 연출은 물리 시간을 바꾸지 않습니다.

중형 85ms, 왕급 95ms의 나무 타격음을 각 세 변주로 제작했습니다. 저음 사인파를 없애고 짧은 타격과 나무 공명을 사용했습니다. 기존 작은 알·발사·경첩·낙하·승리음 15개는 보존했습니다. 전후 비교음 순서는 중형 이전→중형 현재→왕 이전→왕 현재입니다. Suno를 사용하지 않은 자체 합성음입니다.

## 검증 범위

27개 코어 테스트, 음향 연결·발음 제한·음소거 모형 검사, TypeScript와 프로덕션 빌드가 통과했습니다. 독립 Canvas 렌더링으로 배치·접촉·경첩 위치를 확인했습니다. 실제 브라우저 입력, 모바일 및 스피커 청취는 검증하지 못했으므로 손맛과 음색의 최종 평가는 실플레이가 필요합니다.
