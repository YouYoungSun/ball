# 장기 알까기 변경 · 조율 결과

사용자가 요청한 재미의 변경은 장기 그림만 붙이는 것이 아니라 크기와 질량, 상하 전선, 경첩을 함께 게임 규칙에 넣는 것입니다. 개발자·알까기 연출자·소리 담당을 병렬로 진행하고 부모 에이전트가 API·좌표·색·물성·음향 연결을 통합했습니다.

## 개발자 합의

| 말 | 반지름 | 상대 질량 | 최대 발사속도 |
| --- | ---: | ---: | ---: |
| 왕 | 0.45 | 2.80 | 9.8 |
| 차 | 0.39 | 2.00 | 10.5 |
| 포 | 0.37 | 1.80 | 10.8 |
| 상 | 0.34 | 1.40 | 11.2 |
| 마 | 0.33 | 1.30 | 11.4 |
| 사 | 0.27 | 0.90 | 11.7 |
| 졸·병 | 0.24 | 0.65 | 12.0 |

게임용 튜닝 값입니다. 실제 장기알의 무게를 측정한 수치가 아닙니다. 왕은 졸의 약 4.3배 질량입니다. 같은 드래그 비율에서 비슷한 속도로 출발하도록 각 알의 최대 impulse를 `질량 × 최대속도`로 정했습니다. 가벼운 말만 지나치게 빠르게 날아가 무게 효과를 상쇄하지 않게 하기 위한 선택입니다.

동일 발사속도 8의 통제 검사에서 졸→왕 충돌은 왕 최고속도 2.686, 졸 반동 −3.987이었습니다. 왕→왕에서는 대상 왕 최고속도 7.294였습니다. 졸은 왕이 전달한 속도의 약 36.8%를 전달하고 자신은 되튕깁니다. 작은 알로 큰 알을 완전히 못 미는 규칙은 아니므로 가장자리·연쇄·각도를 이용할 여지는 있습니다.

중앙 y=5의 양끝에 폭 0.8, 두께 0.22의 고정 경첩을 놓았습니다. 중앙 길은 비어 있습니다. 경첩의 기하와 실제 충돌벽은 동일한 메타데이터를 참조합니다. 서로 다른 크기의 알 접촉점은 반지름 가중치로, 경첩 접촉점은 벽 표면으로 계산합니다.

## 연출 합의

- 나무판의 분위기는 유지하고 판 가로 점유율을 72.7%에서 94.5%로 늘렸습니다.
- 9선10줄, 양끝 궁성, 중앙 접이선, 두 금속 경첩을 표시합니다. 중국 장기의 강은 그리지 않습니다.
- 각 16개, 총 32개 팔각 나무말입니다. 크기·두께·그림자와 한자 각인을 종류별로 다르게 표시합니다.
- 아래는 청색 초楚, 위는 홍색 한漢입니다. 실제 초기 배치는 보이는 격자 교차점과 일치시켰습니다.
- 선택한 알의 이름과 졸 기준 상대 무게를 표시합니다. Q/E로 16개 알을 순환 선택할 수 있습니다.
- 나무 충돌은 짧은 충격선, 경첩은 짧은 금속 섬광으로 구분합니다. 효과는 물리 상태를 변경하지 않습니다.

## 소리 합의

Suno는 미연결입니다. 외부 녹음·샘플 없이 직접 제작한 원본 PCM WAV 21개를 넣었습니다. 48kHz/16bit/mono이며 발사, 가벼운·중형·중량 나무 충돌, 경첩 금속 충돌, 낙하, 짧은 마침음 각 3변주입니다.

종별 질량은 음색을, 충돌 강도는 볼륨을 선택합니다. 7개 동시 발음 제한과 컴프레서를 사용합니다. 21개 모두 클리핑 0, 앞부분 무음은 −45dBFS 기준 최대 0.104ms였습니다. 실제 스피커/모바일 청취는 아직 하지 못했습니다.

`docs/audio/audition.wav` 순서: 발사 → 가벼운 충돌 → 중형 → 중량 → 경첩 → 낙하 → 마침음. 해당 파일은 비교용이며 실제 게임의 재생 목록에는 포함하지 않습니다.

## 통합 검증

코어 테스트 22개, 음향 API 모형 검사, TypeScript와 Vite 프로덕션 빌드를 통과했습니다. 32알 대기/실제 충돌/샷 종료/경첩 충돌을 Canvas로 렌더하고 좌표 역변환을 검사했습니다. 실제 브라우저 전체 UI, 모바일 터치, 오디오 실청취, 기기 간 온라인 동기화 검증은 남아 있습니다.

AI는 같은 질량과 경첩이 있는 코어에서 10/20/36 후보를 평가합니다. 개발자 환경의 32알 초기 상태 측정은 약 192/349/568ms였으며 모바일 실측이 아닙니다. 기존 Worker 경계를 유지합니다.
