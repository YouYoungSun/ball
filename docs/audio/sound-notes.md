# 장기 알까기 효과음 제작

Suno MCP는 연결되어 있지 않아 사용하지 않았습니다. 외부 녹음·샘플 없이 Python/NumPy/SciPy로 직접 설계한 PCM WAV입니다. 재생 중 즉석 삐 소리를 내던 임시 오실레이터를 실제 오디오 파일로 교체했습니다.

| 이름 | 성격 | 파일 수 | 길이 |
| --- | --- | --- | --- |
| flick | 손가락과 나무 말의 짧은 마찰·놓임 | 3 | 80ms |
| hitSoft | 졸·사의 작고 맑은 또각 | 3 | 75ms |
| hitMedium | 중형 말의 짧은 목질 탁 | 3 | 85ms |
| hitHard | 큰 말의 밀도 높은 짧은 타격 | 3 | 95ms |
| hinge | 짧고 밝은 금속 접촉 | 3 | 160ms |
| fall | 가벼운 목질 반동 세 번의 낙하 | 3 | 360ms |
| win | 절제된 두 번의 나무 마침음 | 3 | 280ms |

48kHz, PCM 16bit, mono. 개별 파일 피크 -3dBFS입니다. v0.4 중·대형은 짧은 잡음 충격으로 넓은 목재 공진을 자극하며, 별도 사인파 몸통을 사용하지 않습니다. 다른 5종은 승인된 v0.3 바이트를 유지합니다.

## v0.3: 경쾌한 타격으로 수정

사용자 피드백에 따라 모든 접촉을 짧고 밝게 조정했습니다. Soft/Medium/Hard는 이전 105/160/225ms에서 75/110/145ms로 줄였습니다. 중량 충돌의 저역 공명은 130Hz·43ms 감쇠에서 190Hz·19ms 감쇠로 바꾸고, 저역 잡음 레이어는 gain .31→.08, 감쇠 62→22ms로 줄였습니다. 경첩의 긴 금속 링과 낙하 첫 타격의 쿵 소리를 줄였습니다.

첫 35ms RMS는 Soft/Medium/Hard 평균 약 -19.9/-20.1/-18.5dBFS로 확인했습니다. Soft의 재생 gain은 .32→.36으로 올려 작은 접촉이 묻히지 않게 했습니다. 짧은 낙하 반동의 gain은 .38로 유지해 떨어진 사건을 읽을 수 있게 했습니다. 전체 클립 길이 때문에 달라지는 RMS 대신 어택 구간을 함께 검사합니다.

`AudioPlayer.event(event, matchState?)`가 말의 kind/질량으로 음색을 선택하고 충돌 강도로 볼륨을 정합니다. 종류별 3개 샘플과 미세 피치 변주를 사용합니다. 동시 발음 7개 제한, 사건별 최소 간격, 마스터 컴프레서로 연쇄 충돌의 과도한 음량을 줄입니다. 파일 로드 실패 시 삐 소리로 대체하지 않고 조용히 둡니다.

프로젝트 루트에서 `python3 scripts/audio/sound-design.py`로 재생성합니다. WAV/manifest는 `public/audio/`, 수치 분석과 비교음은 `docs/audio/`에 출력합니다. `sound-analysis.json`에 길이, 피크, RMS, 앞부분 무음, 클리핑 샘플 수, 스펙트럼 중심을 기록했습니다. 21개 파일 모두 클리핑 0, -45dBFS 기준 앞부분 무음 0.104ms 이하입니다. 실제 브라우저·스피커 청취와 모바일 혼합 검증은 하지 못했습니다.

`audition.wav`와 `audition-v03.wav`: 0.20초부터 flick → hitSoft → hitMedium → hitHard → hinge → fall → win, 약 1.02초 간격입니다. 이전 `audition-v02.wav`와 같은 순서이므로 직접 비교할 수 있습니다. 게임 재생 목록에는 포함하지 않습니다.


## v0.4: 중형·왕 타격만 다시 설계

사용자는 작은 말의 “딱! 딱!”은 좋지만 중형·왕 소리가 별로라고 피드백했습니다. v0.3 중형의 440Hz, 대형의 190/520Hz 사인파 공진은 짧아도 뚜렷한 음높이나 “둥”으로 들릴 가능성이 있어, 두 종류의 합성 방식을 바꿨습니다. 이는 가능한 원인에 대한 설계 판단이며 실제 청취로 확인한 결론은 아닙니다.

중형 85ms, 대형 95ms입니다. 1.3/1.8ms의 불규칙한 잡음 충격으로 낮은 Q의 비정수 공진을 자극하고, 4.5/6.5ms 감쇠의 중역 판 전달음을 더합니다. 350Hz 아래를 줄이고 고역도 제한해 낮은 유음과 금속성 클릭을 함께 줄이려 했습니다. 큰 말의 차이는 긴 저음 대신 초기 몸통의 밀도에서 만들었습니다. 최종 음질·나무 재질감은 사용자가 비교 청취해 판단해야 합니다.

3변주를 모두 유지합니다. 중형/대형의 첫 35ms RMS 평균은 약 -19.5/-17.5dBFS, 개별 피크는 -3dBFS입니다. 여섯 WAV 모두 클리핑 0, -45dBFS 기준 시작 지연 0~0.021ms입니다. 이는 파일 기술 검사이며 음질 검증은 아닙니다. Soft/flick/hinge/fall/win 15개는 `v03-reference/preserved-hashes.json`과 SHA256을 대조해 바이트 동일함을 확인했습니다. 생성기를 다시 돌려도 낙하/승리의 기존 중형 레이어까지 유지합니다.

플레이어의 이벤트 물성 분기는 유지합니다. 두 말 중 큰 질량으로 샘플 하나만 골라 왕+졸, 왕+왕도 대형 소리 1개를 재생합니다. 강도 gain과 기존의 작은 피치 변주도 유지합니다. `node scripts/audio/check-player.ts`에서 21개 디코딩, 7개 이벤트/물성 경로, 왕+왕 1회 재생, 동시발음 제한과 음소거를 확인했습니다. 실제 스피커·브라우저 실청취는 수행하지 못했습니다.

- `audition-v04.wav`: 기존과 같은 7종 순서, 0.20초부터 1.02초 간격.
- `compare-medium-hard-v03-v04.wav`: 0.20초 중형v03 → 1.60초 중형v04 → 3.00초 대형v03 → 4.40초 대형v04. 모두 02번 변주이며 비교 파일 전체에 같은 gain을 적용했습니다.
- `v03-reference/`: 교체 전 중형/대형 6개 WAV와 생성기 원본. 게임의 public 재생 목록에는 없습니다.
- `sound-analysis-v04.json`: 현재 WAV의 기술 분석. `sound-analysis-v03.json`은 이전 분석 보존본.
