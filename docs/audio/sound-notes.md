# 장기 알까기 효과음 제작

Suno MCP는 연결되어 있지 않아 사용하지 않았습니다. 외부 녹음·샘플 없이 Python/NumPy/SciPy로 직접 설계한 PCM WAV입니다. 재생 중 즉석 삐 소리를 내던 임시 오실레이터를 실제 오디오 파일로 교체했습니다.

| 이름 | 성격 | 파일 수 | 길이 |
| --- | --- | --- | --- |
| flick | 손가락과 나무 말의 짧은 마찰·놓임 | 3 | 80ms |
| hitSoft | 졸·사의 작고 맑은 또각 | 3 | 75ms |
| hitMedium | 중형 말의 경쾌한 목질 탁 | 3 | 110ms |
| hitHard | 큰 말의 짧고 단단한 딱 | 3 | 145ms |
| hinge | 짧고 밝은 금속 접촉 | 3 | 160ms |
| fall | 가벼운 목질 반동 세 번의 낙하 | 3 | 360ms |
| win | 절제된 두 번의 나무 마침음 | 3 | 280ms |

48kHz, PCM 16bit, mono. 개별 파일 피크 -3dBFS, 2ms의 짧은 어택입니다. 넓은 대역의 타격 잡음과 비정수비의 감쇠 공명을 조합했습니다. 중량급도 길고 낮은 판 울림 대신 짧은 목질 몸통을 사용하고, 경첩은 높은 금속 접촉으로 구별합니다.

## v0.3: 경쾌한 타격으로 수정

사용자 피드백에 따라 모든 접촉을 짧고 밝게 조정했습니다. Soft/Medium/Hard는 이전 105/160/225ms에서 75/110/145ms로 줄였습니다. 중량 충돌의 저역 공명은 130Hz·43ms 감쇠에서 190Hz·19ms 감쇠로 바꾸고, 저역 잡음 레이어는 gain .31→.08, 감쇠 62→22ms로 줄였습니다. 경첩의 긴 금속 링과 낙하 첫 타격의 쿵 소리를 줄였습니다.

첫 35ms RMS는 Soft/Medium/Hard 평균 약 -19.9/-20.1/-18.5dBFS로 확인했습니다. Soft의 재생 gain은 .32→.36으로 올려 작은 접촉이 묻히지 않게 했습니다. 짧은 낙하 반동의 gain은 .38로 유지해 떨어진 사건을 읽을 수 있게 했습니다. 전체 클립 길이 때문에 달라지는 RMS 대신 어택 구간을 함께 검사합니다.

`AudioPlayer.event(event, matchState?)`가 말의 kind/질량으로 음색을 선택하고 충돌 강도로 볼륨을 정합니다. 종류별 3개 샘플과 미세 피치 변주를 사용합니다. 동시 발음 7개 제한, 사건별 최소 간격, 마스터 컴프레서로 연쇄 충돌의 과도한 음량을 줄입니다. 파일 로드 실패 시 삐 소리로 대체하지 않고 조용히 둡니다.

프로젝트 루트에서 `python3 scripts/audio/sound-design.py`로 재생성합니다. WAV/manifest는 `public/audio/`, 수치 분석과 비교음은 `docs/audio/`에 출력합니다. `sound-analysis.json`에 길이, 피크, RMS, 앞부분 무음, 클리핑 샘플 수, 스펙트럼 중심을 기록했습니다. 21개 파일 모두 클리핑 0, -45dBFS 기준 앞부분 무음 0.104ms 이하입니다. 실제 브라우저·스피커 청취와 모바일 혼합 검증은 하지 못했습니다.

`audition.wav`와 `audition-v03.wav`: 0.20초부터 flick → hitSoft → hitMedium → hitHard → hinge → fall → win, 약 1.02초 간격입니다. 이전 `audition-v02.wav`와 같은 순서이므로 직접 비교할 수 있습니다. 게임 재생 목록에는 포함하지 않습니다.
