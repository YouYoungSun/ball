# 비교 영상

두 3열 영상의 순서는 왼쪽부터 A 실물, B 아케이드, C 무협이다. 각 후보의 개별 MP4도 일반 샷과 강타로 나누었다. 모든 영상은 30fps, 3초이며, 앞 600ms는 준비 동작이다. 개별 영상은 390px, 3열 영상은 열당 300px이다.

이 영상은 동일한 물리 기록을 `@napi-rs/canvas`로 오프라인 렌더링한 무음 영상이다. 실제 브라우저 녹화가 아니며 소리 청취 검증을 나타내지 않는다.

프로젝트 루트에서 Node.js 24, FFmpeg, `@napi-rs/canvas`가 설치된 환경으로 재생성한다. 현재 환경의 `@napi-rs/canvas`는 프로젝트 의존성이 아니라 상위 런타임의 Node 모듈 경로에서 제공되므로, 다른 환경에서는 해당 패키지를 별도로 설치하거나 Node 모듈 경로에 제공해야 한다. 프레임 임시 파일은 프로젝트 상위 `.tmp/lab-capture`에 저장된다.

```sh
node --expose-gc scripts/lab-capture.ts
```
